# AFS Studio 团队内测手册 v0.1

中文摘要:本手册面向内测成员,覆盖从启动服务到完成一次"资产固定 → 连线 → 生成 → 评分"完整创作回路的全部操作。内测的核心验证目标只有一个:**你固定过的资产,系统是否在后续生成里自动遵守了**。请特别留意你在哪一步想绕过系统——绕过点请务必记录反馈。

## 一、启动

```powershell
cd <仓库根目录>
.\.venv\Scripts\python.exe -m apps.cli.main runtime-service --host 127.0.0.1 --port 8790
```

浏览器打开 `http://127.0.0.1:8790/studio/`。

远程生成默认关闭。需要真实出图时,仅在授权范围内设置 `AFS_ALLOW_REMOTE_IMAGE=true` 与 provider 配置;不要设置其他 gate。

当前内测版本只有**图片节点**支持真实生成。视频、音频、脚本和合成节点保留为画布结构节点,发送按钮会禁用并提示通道开发中,不会再生成本地占位结果。

## 二、核心概念(60 秒版)

- **画布与节点**:无限画布,文本/图片/视频/脚本/导演台节点自由创建,连线表示"下游参考上游"。
- **固定资产**:把一张图(上传或生成)连同它的文字特征敲定为人物/场景资产。**敲定过的,后续生成自动遵守。**
- **两层提示词**:你看到并编辑的是"可见提示词";实际发给模型的还会自动附加连线资产的完整特征卡、锁定项和参考图(伴随包),你不需要重复描述人物长相。
- **连线即承诺**:只有连线的资产才会被携带。提示词里点名了未连线资产时,系统会提示你连线,不会静默携带。

## 三、标准创作流程

1. **建人物**:创建图片节点,上传或生成人物图 → 点"固定为资产" → 确认面板中选"人物资产",填 label、签名、特征卡、锁定项(参照 `docs/visual_asset_feature_card_template.zh-CN.md`)→ 固定。节点出现资产标记。
2. **建场景**:同上,选"场景资产"。
3. **写分镜**:创建图片节点写本镜提示词,从人物/场景资产节点**连线**到该节点。
4. **优化提示词**(可选):点优化。面板会显示引用了哪些资产及连线状态;出现"已引用但未连线"时用一键连线补上。
5. **生成**:发送生成。节点上"本次携带"指示显示将注入的资产;出现锁定冲突警告时,确认是改提示词还是临时解除某条锁定(解除仅对本次生效)。
6. **评图回流**:满意的生成图可再次"固定为资产"(必须过确认面板);不满意的留在历史里即可。

补充行为:

- 固定资产成功后,画布撤销(Ctrl+Z)不会撤销已经写入 Runtime 的 fixed asset;如需纠错,后续用退役旧资产、重新固定新资产。
- 节点资产 badge 和 drawer 的"显性资产"卡片可打开只读详情,查看签名、特征卡、锁定项、状态和来源节点。
- 如果资产已退役、被同名新版本替代或不在 fixed 资产库中,生成后 badge 会灰显为"已失效,本次未携带"。
- 优化面板中"未引用 · 可连线"表示项目里存在该资产,但本次可见提示词没有引用或尚未连线;生成不会静默携带。

## 四、必测清单(每位成员至少完整跑一遍)

- [ ] 上传图固定为人物资产,特征卡至少 4 个键
- [ ] 生成图固定为场景资产
- [ ] 连线后优化:优化结果包含资产签名特征
- [ ] 提示词点名未连线资产 → 出现连线建议,一键连线后状态变化
- [ ] 生成请求的"本次携带"指示与实际连线一致
- [ ] 写一条与锁定项冲突的提示词 → 出现冲突警告 → 临时解除一条锁定再生成
- [ ] gate 关闭时生成返回 blocked 且无网络调用(看 safe manifest)
- [ ] (授权后)真实生成一张关键帧,对照特征卡评一次分

## 五、反馈记录格式

每条反馈一行,记在内测共享文档:

```text
[绕过点|缺陷|建议] 步骤编号 | 现象 | 期望 | 截图/artifact id
```

重点收集:哪一步让你想跳过资产固定直接生成?特征卡哪个字段你不知道怎么填?冲突警告是否误报/漏报?

## 六、边界与免责

- 本手册描述 runtime verification 层面的功能;通过内测不等于 human acceptance 或 business validation。
- 不要把 secret、provider key、本地私有素材路径填入任何节点或文档。
- image 授权不代表 video/LLM/ASR/下载授权;开 gate 前先确认任务级授权。
