## 中文摘要

本轮继续长周期 goal-mode，但仍然没有执行 `master` 合并、服务器三端同步、Runtime 重启或 provider smoke。`AFS-T19 Authorized Master Merge + Three-End Sync` 仍需要明确的人类授权；在没有该授权的情况下，本轮继续推进一个本地 deterministic 合同切片：把 T15b 的人工 promotion decision 转换为一个可审计的 Runtime context overlay artifact。

T15a 已经让 `/feedback` 事件携带安全的 `feedback_candidate`，并且默认禁止进入上下文、长期记忆或 Company KB。T15b 增加了人工 promotion decision，只允许操作者把候选反馈标记为 `promote_to_context_overlay`、`reject` 或 `needs_more_evidence`。T15c 在这个基础上只做下一步最小可验证动作：读取已经人工允许的 promotion decision，生成 `runtime_feedback_candidate_context_overlay` artifact，记录这条候选反馈可以被后续本地上下文构建步骤引用。

这个 overlay 不是 provider 上下文注入，也不是 durable memory，也不是 Company KB 规则。它不改 Studio 状态机，不改真实 context resolver，不写 context bundle，不生成媒体，不打开 provider gate。它只是把“人工允许进入下一轮本地上下文”的事实从 decision artifact 变成一个单独可追踪的 overlay artifact，方便后续继续接入 context resolver 或 Studio UI 时不重新解释反馈合同。

## Contract

New public Runtime route:

```text
POST /projects/{project_id}/feedback-candidate-context-overlays
```

Request fields:

- `promotion_decision_artifact_id`
- `overlay_intent`
- `generated_at`

The route:

- reads the source artifact by `promotion_decision_artifact_id`;
- requires the source payload to be `agentflow_runtime_feedback_candidate_promotion_decision`;
- requires the source decision to be `promote_to_context_overlay`;
- requires `context_overlay_allowed=true`;
- verifies project ownership against the source artifact;
- rejects unsafe request payloads;
- writes `runtime_feedback_candidate_context_overlay.json`;
- registers artifact role `runtime_feedback_candidate_context_overlay`;
- writes an `agentflow_run_trace`;
- appends the overlay artifact to project `feedback_refs`.

The overlay artifact explicitly keeps:

- `candidate_included_in_context=true`
- `context_overlay_written=true`
- `context_bundle_written=false`
- `durable_memory_written=false`
- `writes_long_term_memory=false`
